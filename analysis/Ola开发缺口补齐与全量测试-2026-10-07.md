## 二、边界与失败处理

- MCP 本地资源只能来自已批准的执行目录；目录外文件不登记。内嵌文件使用明确的文档、图片、音频和视频 MIME 白名单，单次落盘累计限制 16 MiB，原始响应限制 24 MiB；较大二进制输出转换为文件引用，模型输出仍限制 128 KiB。
- 视频下载单文件上限 512 MiB，空间缓存配额 2 GiB。关闭插件后暂停未完成任务；重新启用恢复已确认的服务商任务。取消失败后继续刷新真实状态，避免把未取消的任务显示为取消成功。
- 已有本地视频任务不强行关联到不相干的聊天。画布独立生成的结果可进入结果中心，但没有真实来源会话的历史任务不能自动返回一个虚构会话。
- SSH 仍按已授权 SFTP 元数据确认结果；同尺寸且秒级修改时间未变化的覆盖会保守地不收集，真实远程服务呈现由用户手测。

| 顺序 | 操作                                                                               | 预期                                                                 |
| ---- | ---------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 1    | 重启应用，进入运行中心和结果中心；已有文件、图片、链接分别预览和复用               | 页面可打开；结果归属正确；复用保留原草稿内容                         |
| 2    | 创建超过 50 个结果或运行；从空列表等待新增；加载下一页                             | 出现继续加载入口；可读到较早记录；后台刷新不丢失已加载页             |
| 3    | 选择第 2 页的一条运行中 Cron，等待完成或失败                                       | 详情和左侧列表同步更新；投递状态独立显示                             |
| 4    | 在 SSH 会话成功生成文件并声明 outputFiles；结果页复用；再修改会话连接尝试复用      | 原连接可添加远程文件；错连接被拒绝；大小写不同的路径不合并           |
| 5    | MCP 分别返回 HTTP 链接、工作目录文件、内嵌 Markdown 和音频；再返回目录外文件或错误 | 有效结果进入索引；音频可作为真实文件打开；越界和失败结果不登记       |
