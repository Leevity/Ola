# Install

Ola 是 Electron 桌面应用。发布版本从 GitHub Releases 获取；从源码开发需要 Node.js 22+、npm 10+。CodeGraph 由 TypeScript/WASM runtime 提供，不需要 .NET 或独立 Worker。

<SignalGrid>
  <Signal title="release" value="Desktop first">
    面向日常使用优先选择安装包，避免本地 native module 环境差异。
  </Signal>
  <Signal title="source" value="Node.js 22+ · npm 10+">
    从源码运行需要安装依赖并启动 Electron + Vite；CodeGraph 随 runtime 构建。
  </Signal>
  <Signal title="data" value="Local only">
    运行时数据默认写入 `~/.ola/`，不要提交到仓库。
  </Signal>
</SignalGrid>

<Callout type="info" title="TypeScript CodeGraph">
  Agent、业务数据和 CodeGraph 均由 TypeScript runtime 提供，不需要 .NET 或外部 Worker。
</Callout>

## Desktop release

<CommandGroup title="Download release" description="选择与你的系统匹配的安装包。">
  <CommandItem
    label="Latest release"

## From source

<CommandGroup title="Run locally" description="用于开发、调试或验证当前仓库。">
  <CommandItem label="Clone" command="git clone https://github.com/Leevity/Ola.git" />
  <CommandItem label="Install" command="cd Ola && npm install" />
  <CommandItem
    label="Verify CodeGraph"
    command="npm run verify:ts-codegraph"
    note="可选：验证 TypeScript/WASM 代码图资源和解析路径。"
  />
  <CommandItem
    label="Start app"
    command="npm run dev"
    note="首次启动 Vite 需要编译较多 React 模块，通常比后续启动慢。"
  />
</CommandGroup>

## Build installers

<CommandGroup title="Build pipeline" description="提交前建议先跑类型检查，再执行构建。">
  <CommandItem label="Type check" command="npm run typecheck" />
  <CommandItem label="Build app" command="npm run build" />
  <CommandItem label="Windows" command="npm run build:win" />
</CommandGroup>

## Local data directory

Ola 的本地数据默认保存在：

```text
~/.ola/
```

| Path        | Purpose           |
| ----------- | ----------------- |
| `data.db`   | SQLite 数据库     |
| `config`    | 本地配置          |
| `agents/`   | 用户可编辑 agents |
| `commands/` | 用户命令          |
| `prompts/`  | 提示词            |

## Docs site

文档站在 `docs/` 目录中，是独立的 Fumadocs + Next.js 应用。

<CommandGroup title="Run docs" description="只开发文档站时不需要启动 Electron 主应用。">
  <CommandItem label="Enter docs" command="cd docs" />
  <CommandItem label="Install deps" command="npm install" />
  <CommandItem label="Start docs" command="npm run dev" note="默认地址为 http://localhost:3000。" />
</CommandGroup>
