# 开发环境搭建 / Development Setup

## 前置要求 / Prerequisites

| 工具       | 版本     | 说明                                                                                                                                                    |
| ---------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Node.js    | 22+      | 推荐使用 LTS 版本，仓库 `engines` 强制 `>=22`、`npm >=10`，过低的版本会在 `preinstall` 被拒                                                             |
| npm        | 10+      | 随 Node.js LTS 安装                                                                                                                                     |
| .NET SDK   | 10       | 必需，用于编译 Native Worker 和 CodeGraph Worker；详见 `sidecars/Ola.Native.Worker`                                                                     |
| Git        | 任意     | 版本控制                                                                                                                                                |
| 原生工具链 | 平台相关 | Windows 需要 MSVC；macOS 需要 Xcode CLT；Linux 需要 `build-essential`；用于 `better-sqlite3`、`@jitsi/robotjs`、`ssh2` 等原生模块的 postinstall rebuild |

## 克隆与安装 / Clone & Install

```bash
git clone https://github.com/Leevity/Ola.git
cd Ola
npm install
```

## 启动开发模式 / Start Dev Mode

```bash
# predev 会在缺失时自动发布 Native Worker 和 CodeGraph Worker（需要 .NET 10）
npm run dev
```

这会同时启动：

- Electron 主进程
- Vite 开发服务器（渲染进程，支持 HMR）

如果 Windows 报 Worker 文件被拒绝访问（`EPERM`），先完全退出 Ola，再重新运行 `npm run native:publish`。

## 项目结构 / Project Structure

```
Ola/
├── src/
│   ├── main/           # Electron 主进程
│   │   ├── index.ts    # 入口
│   │   ├── ipc/        # 30+ IPC 处理器
│   │   ├── db/         # SQLite 数据库（DAO + 迁移）
│   │   ├── channels/   # 消息平台插件（8 个平台）
│   │   ├── cron/       # 定时任务调度器
│   │   ├── mcp/        # MCP 服务器管理器
│   │   └── ssh/        # SSH 连接管理
│   ├── preload/        # 预加载桥接脚本
│   ├── renderer/
│   │   └── src/
│   │       ├── lib/    # 核心库（agent / api / tools / preview）
│   │       ├── stores/ # 15+ Zustand stores
│   │       ├── hooks/  # React hooks
│   │       ├── components/ # UI 组件
│   │       └── locales/    # i18n（en/zh 7 个命名空间）
│   └── shared/         # 主进程/渲染进程共享类型
├── resources/
│   └── agents/         # 子代理定义（.md 文件）
├── docs/               # Fumadocs 文档站点
├── electron.vite.config.ts
├── tsconfig.node.json  # 主进程 TS 配置
└── tsconfig.web.json   # 渲染进程 TS 配置
```

## 类型检查 / Type Checking

```bash
# 检查所有进程
npm run typecheck

# 仅检查主进程
npm run typecheck:node

# 仅检查渲染进程
npm run typecheck:web
```

## 代码规范 / Code Style

```bash
# Lint 检查
npm run lint

# 格式化
npm run format
```

## 路径别名 / Path Aliases

渲染进程使用 `@renderer/*` 别名：

```typescript
// 等价于 src/renderer/src/lib/agent/agent-loop.ts
import { runAgentLoop } from '@renderer/lib/agent/agent-loop'
```

配置在 `tsconfig.web.json` 和 `electron.vite.config.ts` 中。
