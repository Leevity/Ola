# Ola 1.0.6 版本说明

发布状态：已发布。GitHub Actions 运行 `39223957992` 全部成功，Release 已上传并完成校验。

## 本次更新

- 使用「协同工作区」品牌方向，统一蓝紫强调色、深浅色语义、间距和 ola 标识；共享设计变量生成 Web、Android 和 iOS 资源。
- 首次打开提供登录 Ola 与本机使用入口。账户登录以浏览器授权为主，账户资源与本机配置分别呈现。
- 桌面端显示当前工作区、团队模型来源及同步状态，聊天可使用账户授权的团队模型，不必另填本机 API Key。
- 整理设置入口，保留桌面宠物配置，更新关于页功能说明；修复插件切换继承旧滚动位置的问题。
- 补齐部分中文账户与插件文案，区分加载、空资源、同步失败和本机模型配置。

- 更新 Electron、MCP SDK 及相关网络依赖的兼容修复版本，修复发布审计发现的高危和严重依赖项；OAuth 回跳参数不再原样写入启动日志。

- 为 macOS 托盘提供透明单色 ola 模板及 Retina 资源；修复干净环境下的独立运行时构建和无浏览器存储时的状态初始化。

- 修复深色主题危险操作按钮与标签的文字对比度，使用语义前景色；增加独立的真实组件状态审查工具，覆盖错误、加载、禁用、长文本和键盘滚动。

- 发布依赖清单改为读取实际安装包中的依赖名称和版本，避免将开发锁文件当成运行依赖；发布文件使用十六进制 SHA-256 校验。清单明确其应用归档范围。

- 发布流程补充 macOS 未签名 DMG 原生创建、Windows ARM64 压缩兼容、外置依赖清单扫描和安装器主程序烟测；详细故障记录见 `docs/releases/RELEASE-TROUBLESHOOTING.md`。

## 相关客户端与服务

移动端与管理端分别维护版本，不自动套用桌面端 1.0.6。配套改造包括移动端账户页面层级、工作区模型同步反馈，以及网页授权和控制台资源状态。最终交付报告将记录三个仓库各自的提交与构建产物。

## 验证范围与已知限制

PC 与 Android 的真实团队模型对话已有专项通过记录。Android 网页授权回跳、目录撤权/恢复及断网保留配置也已有记录。PC 浏览器授权回跳、其余账户生命周期、全部页面响应布局和最终打包仍需补齐验收。

个人云模型管理、私网模型终端直连尚未完整交付；iOS 运行测试按用户要求暂缓。完整 TypeScript 迁移验收继续依照迁移台账，不以本次模型流程通过替代全量迁移结论。

## 签名与安装包

当前没有开发者发布签名。计划交付的 macOS 包不包含 Developer ID 签名或 Apple 公证；构建工具可能使用 ad-hoc 签名维持可执行文件完整性。Windows 包不包含 Authenticode 签名。

Android APK 必须具备 Android 平台所需的 APK 签名；当前联测包使用开发调试密钥，不代表正式发布身份。未加入 Apple Developer Program 且无签名配置时，不能将未签名 iOS 产物描述为可直接安装到 iPhone 的 IPA。

构建架构、文件名、校验值和下载地址已记录在 GitHub Release `v1.0.6`；实际签名状态仍为未签名/ad-hoc，详见上方限制说明。
