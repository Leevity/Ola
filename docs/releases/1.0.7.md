# Ola 1.0.7 构建候选说明

本次为 `main-ts` 分支源码构建候选。GitHub Actions 将生成各平台安装包；构建状态、产物文件名和校验值以对应工作流与草稿 Release 为准。

## 本次内容

- 收尾 TypeScript runtime 隔离、utilityProcess 生命周期与 Main 侧桥接相关实现和验证材料。
- 补充设计资源同步检查、运行时验证记录和发布质量门禁所需的修复。
- 同步应用版本和 Windows 四段式文件版本至 1.0.7。

## 验收状态

平台安装包需等待 GitHub Actions 完成构建及烟测后确认。真实设备上的多屏幕/远程输入全流程验收、全部平台运行时烟测，以及完整 TypeScript 迁移验收仍以对应 QA 记录和迁移台账为准；本构建候选不宣称这些项目已全部通过。

## 签名

当前 Actions 构建使用无发布证书模式。macOS 未经 Apple 公证，Windows 未经 Authenticode 签名；请以草稿 Release 中生成的产物和校验信息为准。
